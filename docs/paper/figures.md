# Figure Generation

This document tracks how each figure for the paper is generated.

## Figure 1: Architecture Diagram
- **Description:** Depicts the 12-lobe model architecture, showing GATv2 layers, gradient reversal (GRL), and skip connections.
- **Generation Method:** Manually generated as a vector graphic using an external tool (e.g., draw.io, Lucidchart) for publication clarity.

## Figure 2: Calibration Plot
- **Description:** Reliability diagram for the main ensemble classifier.
- **Generation Method:** Generated automatically by `src/run_evaluation.py` and saved to `results/paper_figures/`.

## Figure 3: Learning Curve
- **Description:** Sample efficiency plot showing model performance vs. training data percentage.
- **Generation Method:** Generated by `src/experiments/run_learning_curve.py`.
